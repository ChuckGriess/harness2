# Triage a candidate

Keep it only if every answer is yes:
1. Dated inside the window, confirmed on the primary source (not only an aggregator)?
2. From, or directly about, someone or something on the watchlist for this topic?
3. Changes what a practitioner can build, learn or decide now: a usable release, API or SDK
   change, pricing or limit change, deprecation, course, open model or dataset, governance or
   disclosure decision, or substantive essay?
4. Not a duplicate of an item already kept? If it is, add its URL to that item instead.

Write the why-it-matters line from the reader's side: what they can now do, stop doing, or
should watch. Avoid adjectives that only restate the announcement.
